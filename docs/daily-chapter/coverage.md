# Daily Chapter quotation candidates

500 exact source-matched passages from 100 books; 164 target books total, including the launch roster. **0 approved quotations and 0 scheduled editions in this bank.** These counts describe candidates, not the agreed 500 quiz-ready quotation reserve.

Five whole paragraphs per source book, 8–60 words each, selected from the first three body-text chapters with suitable passages where available. Whitespace is collapsed; wording and punctuation are retained. Chapter headings, epigraphs and paragraphs with note references are excluded. Selection is mechanical: difficulty, spoilers, discriminatory language, ambiguity, distractors, theme fit and the explanation need editorial review. Some passages may be unsuitable. Theme tags are draft classifications of books; a passage need not express every book theme.

Each question links to a fixed Git revision and records its translation, paragraph location, source-file hash and normalized-text hash. Source metadata and proof locations are included in the JSON. Quotation reuse rights are assumed cleared on the project owner's instruction. Candidates remain unapproved only for editorial review; rights are not a pending task.

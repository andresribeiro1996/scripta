# Pre-2002 BNP Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let `import-bnp.mjs` import the national library's pre-2002 set with clean titles, and give BNP books dated before 2002 covers by their own ISBN only.

**Architecture:**
- The OAI set becomes an explicit parameter of the existing BNP harvest and import. The script's `--pre-2002` flag picks the 1935–2001 set and never writes the sync cursor.
- The mapper's text cleaning rewrites the pre-2002 `<display= sort>` and `<article >` markers.
- `findBestCover` gains an ISBN-only mode, which `processBook` turns on for `bnp` books dated before 2002.

**Tech Stack:** TypeScript backend (Fastify, `node:sqlite`), `node:test` via `tsx --test`.

**Spec:** `docs/superpowers/specs/2026-10-24-pre-2002-bnp-import-design.md`

## Global Constraints

- No new dependencies.
- No code comments.
- New tests go into the existing test files named below. They are already in `backend/package.json`'s explicit `test` list, so no list change is needed.
- Verify with `npm run build --workspace @scripta/shared && npm run typecheck --workspace backend && npm test --workspace backend` before each commit.
- Set names are exactly `bibliografianacional` (2002+) and `bibliografianacional2001` (pre-2002).
- The ISBN-only rule is exactly: `created_by === "bnp"`, `year !== null` and `year < 2002`.
- The pre-2002 default `--from` is exactly `2013-06-01`. The default without the flag stays `2000-01-01`.

## Review Focus

- **A 2002+ BNP book losing title search.** The rule must not catch a `bnp` book from 2005 (Task 3 test).
- **A `bnp` book with no year.** It keeps title search (Task 3 test).
- **The 6-hourly sync cursor overwritten by a pre-2002 run,** even one given `cursorOnSuccess` (Task 2 test).
- **Marker stripping eating real angle brackets.** `<jardim>` with no `=` and no trailing space stays (the existing test in `bnpRecord.test.ts`, plus a Task 1 assertion).
- **The upgrade lane still asking Apple by title for an old BNP book.** It must not (Task 3 test, upgrade lane).

# Work Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One page per catalog work, at `/work/<id>` on web and mobile. It shows the book, your copy, the readers you may see, and the public games that use it.

**Architecture:**
- A new backend `works` module owns no data. It serves `GET /works/:id` by composing one by-work read from each owning module: books, library, community, tier lists, arena and quizzes. app.ts wires those reads in as plugin options.
- Shared response types and label helpers live in `@scripta/shared`. Web and mobile each render the four sections and link in from the existing book, game, mural and feed views.

**Tech Stack:** Fastify/TypeScript, `node:sqlite`, `node:test` via `tsx --test`, `@scripta/shared`, React + react-router + TanStack Query (web), Expo Router + TanStack Query (mobile).

**Spec:** `docs/superpowers/specs/2026-10-06-work-page-design.md`

## Rulings on spec gaps

Fact-finding on 2026-10-06 against main `9a11e597` found these gaps. Each is decided here, and each costs a rework if wrong.

1. **Index already exists.** `idx_library_books_work ON library_books(work_id, user_id)` is created in `library/adapters/sqlite/connection.ts:47`, so no index work is needed.
2. **`mine.rating` is a number.** It is `1–5` or `null`, the finish feeling stored as `FinishRating`. The spec's `string | null` was wrong, and clients label it with `FINISH_FEELINGS`.
3. **`mine.highlightCount` excludes reader notes.** It counts `highlights` entries whose `Type !== "review"`, because notes are stored as reviews.
4. **The viewer's edition** is the edition whose ISBN equals the viewer's copy ISBN, with hyphens and spaces removed. If none matches, no edition is marked `mine`. The page then uses the viewer's copy `cover_url` when it is set.
5. **Readers without a username are dropped**, from both rows and counts, as Discover drops authors without one.
6. **Game owners:**
   - a promoted tier list (`owner_user_id = '__app__'`) has owner `"app"`;
   - a game whose owner has no resolvable profile is dropped.
7. **Reader visibility lives in the community public API** as `readerVisibility`. It needs only the community repository, so the existing `createCommunityPublicApi(repo)` factory can carry it. The works service resolves profiles itself, with auth's `resolvePublicReaderProfiles`, and glyphs with library's `readerGlyphFor`.
8. **Signed-out "Your copy" slot.** Web and mobile both have `AddBookSheet({ book: { title, author, isbn, coverUrl }, onClose })`, and it already shows a sign-in link when signed out. So whenever `mine` is `null`, the slot shows "Not in your library" plus an "Add to library" button that opens that sheet, signed in or not.
9. **Mobile route is signed-in only, and the Android link claim ships separately.** It lives in `(app)/(home,arena,library)/work/[id].tsx`, behind the `(app)` sign-in gate, like `u/[username]`. A signed-out deep link goes through login and back, using the gate's existing `returnTo`.
10. **Mobile murals get no way in.** They have no book-block detail to link from (`MuralCanvas` blocks are not pressable).
11. **Web tier-list results link from their result tiles.** Web has no "Book votes" sheet, so the tiles in `TierlistResultsView` link to the work page. Mobile links from its "Book votes" sheet.
12. **Profile links on web are signed-in only.** `/community/u/:username` sits behind `RequireAuth`, so reader rows link to profiles only for signed-in viewers.
13. **Feed links ship with each client PR, not with the backend.** The backend PR adds `workId` to new event payloads and to `DigestBook` (optional field). The web PR changes `digestTarget` and `activityRow`; the mobile PR changes `digestRoute`. Web never links to `/work/` before that route exists.
14. **Client tests:**
    - web: `renderToString` tests of a pure `WorkPageView` component (the `test-mural-save.mts` precedent);
    - mobile: pure view-model tests (`*.test.ts`), since neither client has a DOM or native renderer in tests;
    - shared label helpers: tested in `@scripta/shared`.
15. **Reader order:** followed first, then others. Within each group, by username, case-insensitive.

## Global Constraints

- Route: `GET /works/:id`, unauthenticated, optional viewer via `getOptionalAuthenticatedUser`, `Cache-Control: no-store`, per-IP rate limit `{ max: 30, timeWindow: "1 minute" }` in its own scope.
- Unknown id → 404 `{ "error": "No book with that id." }`. Catalog failure → `WorkResolutionError` → 503 through the global handler. Readers and games failures propagate as 500; never an empty section.
- A merged-away id answers with `work.id` set to the canonical id; clients replace the URL without a history entry.
- Readers cap: 50 rows total, followed first. Games cap: 20 per kind. `counts` cover every reader the viewer may see.
- Reader rows carry username, avatar, optional glyph, status and `published` only. No feeling, dates or highlights.
- `readers.followed`: viewer follows them AND (`published` OR shares reading). `readers.others`: published, not in `followed`, not the viewer. Signed out: `followed` empty.
- Published games: tier lists with `vote_code IS NOT NULL`; tournaments with `status != 'seeding'`; quizzes with `vote_code IS NOT NULL`. Paths: `/vote/<voteCode>`, `/arena/<id>`, `/play/<voteCode>`.
- Every by-work query takes `aliasIds` (canonical id plus ids whose `merged_into` is the canonical id; merges are kept one hop deep).
- No code comments (repo rule). The *why* goes in commit messages.
- Backend test preambles set every `*_DB_PATH` the code opens, including `COVERS_DB_PATH`. Run backend tests as CI does: `cd backend && DOTENV_CONFIG_PATH=/nonexistent/.env npm test`. New `*.test.ts` files join the explicit list in `backend/package.json`'s `"test"` script.
- Shared is consumed from `dist`: run `npm run build --workspace @scripta/shared` before backend, frontend or mobile typecheck/tests.
- After each task: that package's typecheck, lint (frontend) and tests. Frontend: `npm run typecheck --workspace frontend && npm run lint --workspace frontend && npm test --workspace frontend`. Mobile: `EXPO_PUBLIC_API_URL=http://localhost npm run typecheck --workspace mobile && EXPO_PUBLIC_API_URL=http://localhost npm test --workspace mobile`.
- UI: check `DESIGN.md` before adding colors, spacing or radii; sentence case; one primary button per screen; mobile `Text` comes from `ui/Text`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Stage and commit in one command.

## Review Focus

1. **The viewer holds the work and is published.** They never appear in their own readers list, and counts exclude them. Test in Task 6.
2. **A holder with no username, or a followed user who neither publishes nor shares reading.** They are absent and uncounted. Tests in Tasks 4 and 6.
3. **A copy, tier list, tournament or quiz stored on a merged-away work id.** It is still found when the page is requested by the canonical id. A request by the old id answers the canonical id. Tests in Tasks 2, 3, 5 and 6.
4. **A keyless work with no summary and no cover.** The page renders with `summary: null` and `coverUrl: null`, and both clients show a cover placeholder and no "About" text. Tests in Tasks 2 and 8.
5. **A game whose owner has no profile, and a promoted list.** The first is dropped; the second shows "Scripta". Tests in Task 6 (backend) and Task 8 (web label).

```ts
  if (status === 2) return "Finished";
  if (status === 1) return "Reading";
  return "Wants to read";
}

export function readerCountsLabel(counts: { readers: number; finished: number }): string {
  if (counts.readers === 0) return "No readers yet";
  const readers = `${counts.readers} ${counts.readers === 1 ? "reader" : "readers"}`;
  return counts.finished > 0 ? `${readers} · ${counts.finished} finished` : readers;
}

export function gameOwnerLabel(owner: ReaderProfile | "app"): string {
  return owner === "app" ? "Scripta" : owner.username;
}

export function editionLabel(edition: WorkEdition): string {
  const parts = [edition.language, edition.year === null ? null : String(edition.year), edition.isbn].filter((part): part is string => part !== null);
  return parts.length > 0 ? parts.join(" · ") : "Edition details unknown";
}
```

```ts
}
```

```ts
import type { DatabaseSync } from "node:sqlite";
import { openLibraryDb } from "./adapters/sqlite/connection.js";

export type HolderStatus = 0 | 1 | 2;
export type ViewerCopy = { bookKey: string; readStatus: HolderStatus; rating: number | null; highlightCount: number; isbn: string | null; coverUrl: string | null };

const statusOf = (value: unknown): HolderStatus => (value === 2 ? 2 : value === 1 ? 1 : 0);
const isRecord = (value: unknown): value is Record<string, unknown> => typeof value === "object" && value !== null && !Array.isArray(value);

export function createWorkHolders(db: DatabaseSync) {
  const holdersStmt = db.prepare(`SELECT user_id, position, read_status FROM library_books WHERE work_id IN (SELECT value FROM json_each(?)) ORDER BY user_id, position`);
  const copyStmt = db.prepare(`SELECT position, book_key, read_status, isbn, cover_url FROM library_books WHERE user_id = ? AND work_id IN (SELECT value FROM json_each(?)) ORDER BY position LIMIT 1`);
  const documentStmt = db.prepare(`SELECT data FROM library_documents WHERE user_id = ?`);

  function holdersOfWorks(workIds: string[]): Array<{ userId: string; readStatus: HolderStatus }> {
    if (workIds.length === 0) return [];
    const seen = new Set<string>();
    const holders: Array<{ userId: string; readStatus: HolderStatus }> = [];
    for (const row of holdersStmt.all(JSON.stringify(workIds)) as Array<{ user_id: string; read_status: number | null }>) {
      if (seen.has(row.user_id)) continue;
      seen.add(row.user_id);
      holders.push({ userId: row.user_id, readStatus: statusOf(row.read_status) });
    }
    return holders;
  }

  function copyOfWork(userId: string, workIds: string[]): ViewerCopy | undefined {
    if (workIds.length === 0) return undefined;
    const row = copyStmt.get(userId, JSON.stringify(workIds)) as { position: number; book_key: string; read_status: number | null; isbn: string | null; cover_url: string | null } | undefined;
    if (!row) return undefined;
    const document = documentStmt.get(userId) as { data: string } | undefined;
    const parsed: unknown = document ? JSON.parse(document.data) : null;
    const book = isRecord(parsed) && Array.isArray(parsed.books) && isRecord(parsed.books[row.position]) ? parsed.books[row.position] as Record<string, unknown> : {};
    const rating = typeof book.Rating === "number" && Number.isInteger(book.Rating) && book.Rating >= 1 && book.Rating <= 5 ? book.Rating : null;
    const highlights = Array.isArray(book.highlights) ? book.highlights.filter((h) => isRecord(h) && h.Type !== "review").length : 0;
```

```ts
import type { IdentityKey, ReaderProfile, WorkGameRef, WorkPage, WorkReader } from "@scripta/shared";
import type { CatalogWorkPage } from "../books/index.js";
import type { ViewerCopy } from "../library/index.js";

type GameByWork = { id: string; name: string; path: string; ownerUserId: string | null };
type Visibility = { followed: boolean; published: boolean; showGlyph: boolean };

export type WorksDeps = {
  getWorkPage(id: string): CatalogWorkPage | undefined;
  holdersOfWorks(workIds: string[]): Array<{ userId: string; readStatus: 0 | 1 | 2 }>;
  copyOfWork(userId: string, workIds: string[]): ViewerCopy | undefined;
  readerVisibility(viewerId: string | null, userIds: string[]): Map<string, Visibility>;
  resolveProfiles(userIds: string[]): Map<string, ReaderProfile>;
  readerGlyphFor(userId: string): IdentityKey | null;
  tierlists(workIds: string[], limit: number): GameByWork[];
  arenas(workIds: string[], limit: number): GameByWork[];
  quizzes(workIds: string[], limit: number): GameByWork[];
};

const READER_CAP = 50;
const GAME_CAP = 20;
const isbnKey = (isbn: string | null) => (isbn ? isbn.replace(/[\s-]/g, "") : null);
const byUsername = (a: WorkReader, b: WorkReader) => a.username.toLowerCase().localeCompare(b.username.toLowerCase());

export function createWorksService(deps: WorksDeps) {
  function games(workIds: string[]) {
    const lists = { tierlists: deps.tierlists(workIds, GAME_CAP), arenas: deps.arenas(workIds, GAME_CAP), quizzes: deps.quizzes(workIds, GAME_CAP) };
    const owners = deps.resolveProfiles([...new Set(Object.values(lists).flat().flatMap((game) => (game.ownerUserId ? [game.ownerUserId] : [])))]);
    const refs = (items: GameByWork[]): WorkGameRef[] => items.flatMap((game) => {
      const owner = game.ownerUserId === null ? "app" as const : owners.get(game.ownerUserId);
      return owner ? [{ id: game.id, name: game.name, owner, path: game.path }] : [];
    });
    return { tierlists: refs(lists.tierlists), arenas: refs(lists.arenas), quizzes: refs(lists.quizzes) };
  }

  function readers(workIds: string[], viewerId: string | null): WorkPage["readers"] {
    const holders = deps.holdersOfWorks(workIds).filter((holder) => holder.userId !== viewerId);
    const visible = deps.readerVisibility(viewerId, holders.map((holder) => holder.userId));
    const profiles = deps.resolveProfiles([...visible.keys()]);
    const followed: WorkReader[] = [];
    const others: WorkReader[] = [];
    for (const holder of holders) {
      const seen = visible.get(holder.userId);
      const profile = profiles.get(holder.userId);
      if (!seen || !profile) continue;
      const glyph = seen.showGlyph ? deps.readerGlyphFor(holder.userId) : null;
      const reader: WorkReader = { ...profile, ...(glyph ? { readerGlyph: glyph } : {}), readStatus: holder.readStatus, published: seen.published };
      (seen.followed ? followed : others).push(reader);
    }
    followed.sort(byUsername);
    others.sort(byUsername);
    const all = [...followed, ...others];
    const shownFollowed = followed.slice(0, READER_CAP);
    return {
      followed: shownFollowed,
      others: others.slice(0, READER_CAP - shownFollowed.length),
      counts: { readers: all.length, finished: all.filter((reader) => reader.readStatus === 2).length }
    };
  }

  return {
    getPage(id: string, viewerId: string | null): WorkPage | undefined {
      const work = deps.getWorkPage(id);
      if (!work) return undefined;
      const copy = viewerId ? deps.copyOfWork(viewerId, work.aliasIds) : undefined;
      const mineIsbn = isbnKey(copy?.isbn ?? null);
      const mineEdition = mineIsbn ? work.editions.find((edition) => isbnKey(edition.isbn) === mineIsbn) : undefined;
      const summary = mineEdition?.summary ?? work.editions.find((edition) => edition.summary)?.summary ?? null;
      const coverUrl = copy?.coverUrl ?? mineEdition?.coverUrl ?? work.editions.find((edition) => edition.coverUrl)?.coverUrl ?? null;
      return {
        work: {
          id: work.id,
          title: work.title,
          author: work.author,
          summary,
          coverUrl,
          editions: work.editions.map((edition) => ({ bookId: edition.bookId, title: edition.title, language: edition.language, year: edition.year, isbn: edition.isbn, mine: edition === mineEdition }))
        },
        mine: copy ? { bookKey: copy.bookKey, readStatus: copy.readStatus, rating: copy.rating, highlightCount: copy.highlightCount } : null,
        readers: readers(work.aliasIds, viewerId),
        games: games(work.aliasIds)
      };
    }
  };
}

export type WorksService = ReturnType<typeof createWorksService>;
```

`workScreenModel.ts`:

```ts
import { FINISH_FEELINGS, gameOwnerLabel, readerCountsLabel, readerStatusLabel, type WorkGameRef, type WorkPage, type WorkReader } from "@scripta/shared";

const readerRow = (reader: WorkReader) => ({ username: reader.username, avatarUrl: reader.avatarUrl, readerGlyph: reader.readerGlyph, status: readerStatusLabel(reader.readStatus), linksToProfile: reader.published });

export function workScreenSections(page: WorkPage) {
  const { mine, readers, games } = page;
  const feeling = mine?.rating ? FINISH_FEELINGS.find((f) => f.rating === mine.rating)?.label ?? null : null;
  const kinds: Array<[string, string, WorkGameRef[]]> = [["tierlist", "Tier list", games.tierlists], ["arena", "Tournament", games.arenas], ["quiz", "Quiz", games.quizzes]];
  const gameRows = kinds.flatMap(([key, label, list]) => list.map((game) => ({ key: `${key}-${game.id}`, title: game.name, detail: `${label} · ${gameOwnerLabel(game.owner)}`, path: game.path })));
  return {
    about: page.work.summary,
    mine: mine ? { status: readerStatusLabel(mine.readStatus), detail: [feeling, `${mine.highlightCount} ${mine.highlightCount === 1 ? "highlight" : "highlights"}`].filter(Boolean).join(" · ") } : null,
    countsLabel: readerCountsLabel(readers.counts),
    readerGroups: [
      { title: "People you follow", rows: readers.followed.map(readerRow) },
      { title: "Other readers", rows: readers.others.map(readerRow) }
    ].filter((group) => group.rows.length > 0),
    games: gameRows,
    gamesEmpty: gameRows.length === 0
  };
}
```

```ts
import type { WorkPage } from "@scripta/shared";

export function fetchWork(id: string, signedIn: boolean) {
```

`features/works/WorkScreen.tsx` follows `ArenaViewScreen`. It takes `{ id }`, uses `useAuth()` and `useQuery({ queryKey: ["works", id], queryFn: () => fetchWork(id, Boolean(user)), retry: false })`, and renders:
- **Pending:** a `Skeleton`.
- **Error:** `ErrorState`. Its action is "Back" for a permanent error (`isPermanentError(query.error)`, which covers the 404 "No book with that id."), and "Retry" with `refetch` otherwise.
- **Merged-away id:** when `query.data.work.id !== id`, a `useEffect` calls `router.replace(`/work/${query.data.work.id}`)`.
- **Header:** `<Stack.Screen options={{ headerShown: true, title: work.title, headerRight: () => <HeaderActions><IconButton framed name="share" accessibilityLabel="Share book" onPress={...} /></HeaderActions> }} />`. The share press sets `shareUrl` from `await publicContentUrl(`/work/${encodeURIComponent(work.id)}`)`, and `<ContentShareSheet visible={shareUrl !== null} onClose={() => setShareUrl(null)} title={work.title} url={shareUrl} />` shows it.
- **Body:** a `ScrollView` inside `Screen`. Every section title is `Text` with `typography` tokens, rows use the card style `PeoplePane` uses, and spacing and radii come from `ui` tokens. The sections:
  1. cover (`BookCover`), title and author;
  2. "About this book" when `model.about` is set, then the editions list using `editionLabel`;
  3. "Your copy": either `model.mine.status` with `detail`, or "Not in your library" plus `<Button label="Add to library" variant="primary" onPress={() => setAdding(true)} />`. This is the screen's one primary button;
  4. "Readers": `countsLabel`, then each group's title and rows. A row is `AuthorAvatar`, username, `ReaderGlyph` and status, and it is pressable only when `linksToProfile` (calls `openProfile(username)`);
  5. "Games": each row `router.push(row.path as never)`, or the empty line "No public games use this book yet."
- **Add sheet:** `{adding ? <AddBookSheet book={{ title: work.title, author: work.author, isbn: firstEdition?.isbn ?? null, coverUrl: work.coverUrl }} onClose={() => { setAdding(false); void query.refetch(); }} /> : null}`, where `firstEdition` is the first edition with an ISBN, else the first edition.

  - Until then, `/work/` links open on the web.
  
  If wrong, shared links don't open the app until that build.
- **No data migration.** The index already exists, and older feed events keep their payloads.

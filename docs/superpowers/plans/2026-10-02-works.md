# Works above editions: implementation plan

> **For agentic workers:** implement task by task, verify each, commit each task separately. Steps use checkbox (`- [ ]`) syntax. Run a spec review and a quality review after each task (`.claude/agents/`).

**Goal:** Every catalog edition belongs to a work, works follow Open Library's
grouping (translations included), and every edition records its language when
a source states it. No user-visible change.

**Spec:** `docs/superpowers/specs/2026-10-01-works-design.md`.

**Base:** latest `main`. Other sessions are active in `backend/src/modules/books`
(fast import lanes, the Portuguese publisher importer); rebase on `main` before
starting and again before the PR.

**Where work keys come from today:** every write goes through two repository
methods in `backend/src/modules/books/adapters/sqlite/sqliteBooksRepository.ts`:
`createBook({ …, workKey })` and `setWorkKey(id, key)` (fill-only,
`normalizeWorkKey` validates `OL…W`). Callers: the seed (`seed/seedCatalog.ts`),
the publisher importer (`seed/importPublisherCovers.ts`), catalog search and
details (`booksService.ts`).

**Rules:** root `AGENTS.md`, `backend/AGENTS.md`. No code comments. New
`*.test.ts` files go into `backend/package.json`'s `test` list. Verify with:

```
npm run build --workspace @scripta/shared
npm run typecheck --workspace backend
npm test --workspace backend
```

## Task 1: Schema

**Files:** `backend/src/modules/books/adapters/sqlite/{books.sql,connection.ts}`,
`backend/src/modules/books/domain/types.ts`, repository tests.

- [ ] `works (id TEXT PRIMARY KEY, ol_work_key TEXT UNIQUE, title TEXT NOT NULL,
  author TEXT NOT NULL, merged_into TEXT REFERENCES works(id), created_at TEXT NOT NULL)`.
- [ ] `books` gains `work_id TEXT REFERENCES works(id)`, `language TEXT` and
  `work_checked_at TEXT`, with the existing `PRAGMA table_info` + `ALTER TABLE`
  pattern in `connection.ts`, plus `CREATE INDEX IF NOT EXISTS
  idx_books_work ON books(work_id)` and an index serving Task 5's query
  (`isbn IS NOT NULL AND ol_work_key IS NULL`, oldest `work_checked_at` first).
- [ ] `BookRow` gains the three fields.

## Task 2: Every edition gets a work

**Files:** `sqliteBooksRepository.ts`, `domain/ports.ts`, repository tests.

- [ ] Inside the transactions of `createBook` and `setWorkKey`, assign the
  book's work:
  - with an `ol_work_key`: the work with that key, created on first sight with
    this edition's title and author;
  - without one: a new work of its own.
- [ ] When `setWorkKey` gives a key to an edition that already had a keyless
  work, move the edition to the keyed work; if the old work has no editions
  left, set its `merged_into` to the new work.
- [ ] Tests: two editions with one key share a work; a keyless edition gets
  its own; a key arriving later moves it and leaves `merged_into`; a key
  arriving for a work that already has other editions keeps them all together;
  `setWorkKey` on an edition that already has a key changes nothing (fill-only,
  as today).

## Task 3: Backfill existing editions

**Files:** `sqliteBooksRepository.ts`, `backend/src/modules/books/plugin.ts`,
tests.

- [ ] Repository: `assignMissingWorks(limit)` assigns works (Task 2's rule) to
  up to `limit` editions with `work_id IS NULL` in one transaction and returns
  how many it did.
- [ ] `plugin.ts`: after startup, loop `assignMissingWorks(500)`, awaiting
  `setImmediate` between batches, until it returns less than 500; one `info`
  log line with the total; errors to `app.log.error`, never crashing boot. The
  seed is ~50,000 editions, so this must not run as one transaction.
- [ ] Test: a catalog of mixed keyed and keyless editions ends fully assigned,
  with keyed editions grouped.

## Task 4: Edition languages

**Files:** `backend/src/modules/books/domain/normalize.ts` (or a new
`domain/language.ts`), `sqliteBooksRepository.ts`, `seed/seedCatalog.ts`,
`seed/rankedWorks.ts` (the seed entry), `seed/importPublisherCovers.ts`, tests.

- [ ] `editionLanguage(marcCodes: string[], isbn: string | null): string | null`.
  Maps Open Library's MARC codes to two-letter tags (`eng`→`en`, `por`→`pt`,
  `spa`→`es`, `fre`→`fr`, `ger`→`de`, `ita`→`it`, `dut`→`nl`, `cat`→`ca`,
  `glg`→`gl`, `jpn`→`ja`, `chi`→`zh`, `rus`→`ru`); the first mappable code
  wins; none mappable → `null`. For `pt`, the ISBN's registration group sets
  the region: `978972…`/`978989…` (and ISBN-10 `972…`/`989…`) → `pt-PT`,
  `97885…`/`97865…` (ISBN-10 `85…`/`65…`) → `pt-BR`, else `pt`. The books
  module's `PORTUGUESE_ISBN13_PREFIXES`/`PORTUGUESE_ISBN10_PREFIXES`
  (`domain/normalize.ts`) list both countries together; split them by
  country rather than adding a second list.
- [ ] Repository `setLanguage(id, tag)`, fill-only like `setWorkKey`.
- [ ] The seed entry already carries its list's `lang` (`SeedEntry.lang`);
  pass it into `seedBook` and set it. The publisher importer's
  `lookupOpenLibrary` (`backend/scripts/import-publisher-covers.mjs`) fetches
  `/isbn/{isbn}.json` but returns only title, author and work key
  (`OpenLibraryEdition`); add `languages`, and set the language from it,
  falling back to `por`. Put the parsing of that record in the Open Library
  adapter so Task 5 reuses it.
- [ ] Tests: the mapping table, the three Portuguese regions, unknown codes,
  fill-only behaviour, the seed and importer setting it.

## Task 5: Look up missing work keys in the background

**Files:** `backend/src/modules/books/plugin.ts`, the Open Library adapter
(`adapters/openlibrary/`), `booksService.ts` or a small new module, tests.

- [ ] A slow loop: every 2 s, pick the edition with an ISBN, no
  `ol_work_key`, and the oldest `work_checked_at` (never checked first, then
  older than 30 days); fetch `https://openlibrary.org/isbn/{isbn}.json`
  through the existing `openLibraryThrottle`; store `works[0].key` with
  `setWorkKey` (which re-assigns the work) and `languages` with `setLanguage`;
  set `work_checked_at` whether or not anything was found. One request in
  flight at most, so user-facing Open Library lookups keep their share of the
  throttle.
- [ ] An unref'd timer cleared in `onClose`; a fetch error is logged and the
  edition is marked checked, so one bad ISBN never stalls the loop.
- [ ] Tests with a fake fetch: a hit stores key and language and moves the
  edition to the keyed work; a 404 marks it checked; the next pick skips
  recently checked editions.

## Task 6: Document it

- [ ] `backend/README.md`, books section: works, `merged_into`, edition
  languages and their sources, the backfill and the background lookup rate.

## After deploy (the user runs it)

```
railway ssh --service scripta -- node -e 'const { DatabaseSync } = require("node:sqlite"); const db = new DatabaseSync("/data/covers.sqlite", { readOnly: true }); console.table(db.prepare("SELECT (SELECT COUNT(*) FROM works) AS works, (SELECT COUNT(*) FROM books WHERE work_id IS NULL) AS unassigned, (SELECT COUNT(*) FROM books WHERE ol_work_key IS NULL AND isbn IS NOT NULL) AS keyless").all()); console.table(db.prepare("SELECT language, COUNT(*) AS editions FROM books GROUP BY language ORDER BY editions DESC").all())'
```

`unassigned` should be 0 once the backfill finishes; `keyless` should fall
over the following days.
